# Student Performance & Placement Analyzer

## Project Description
This project is a Python-based system for managing student academic performance and placement information.

## Features
- Add student
- View all students
- Search student
- Update marks
- Delete student
- Calculate CGPA and grades
- Class performance analysis
- Placement analysis
- Data visualization

## Technologies Used
- Python
- Jupyter Notebook
- SQLite
- NumPy
- Pandas
- Matplotlib
